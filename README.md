# Tic Tac Toe

A simple Tic Tac Toe game built with HTML, CSS, and JavaScript.

## Features

* Two-player gameplay
* Winner detection
* Draw detection
* New Game button
* Reset Game button
* Responsive UI

## Technologies Used

* HTML
* CSS
* JavaScript
